# 학교 AI 학습·업무 도우미

Copilot Studio 에이전트를 웹페이지에서 이용할 수 있도록 연결한 교육용 프로젝트입니다. 글쓰기, 요약, 문제 해결 등 학교에서 활용할 수 있는 AI 대화를 목표로 합니다.

- [실행 사이트](https://sinnarasam.github.io/ai/)
- [웹 화면 코드](index.html)
- [테스트 절차](docs/TESTING.md)
- [질문 30개 및 결과 기록표](tests/test-cases.csv)
- [검증 기록](docs/VERIFICATION.md)

## 현재 확인된 범위

| 항목 | 확인 상태 |
|---|---|
| 웹 화면 | HTML·CSS로 구성 |
| AI 연결 | Copilot Studio iframe |
| 응답 생성 | 외부 에이전트 담당 |
| 모델 분배 | 내부 설정 미확인 |
| 웹 검색 | 도구 실행 미검증 |
| 파일 첨부 | URL에서 비활성화 |
| Power Automate | 코드에서 확인 불가 |

멀티 모델 분배, 파일 분석, 웹 검색은 프로젝트의 목표 기능입니다. 소개 문구만으로 구현 완료로 간주하지 않습니다. 이 저장소에는 Copilot Studio 내부 설정, 솔루션 내보내기 파일, 모델 연결 정보가 포함되어 있지 않습니다.

## 사용 방법

1. 실행 사이트를 엽니다.
2. 페이지 가운데 Copilot Studio 채팅창이 표시되는지 확인합니다.
3. **채팅창 내부 입력란**에 질문을 입력합니다.
4. 채팅창이 보이지 않으면 하단의 새 창 열기 링크를 이용합니다.
5. 로그인 안내가 나오면 승인된 계정으로 로그인합니다. 이용 권한은 운영 환경에 따라 다릅니다.
6. 중요한 답변은 원문과 비교합니다. 개인정보·비공개 자료는 입력하지 않습니다.

파일 업로드는 현재 검증 대상입니다. 이 페이지가 PDF·Word·Excel·PPT 등 모든 형식의 분석을 지원한다고 보장하지 않습니다.

## 구조

브라우저에서 GitHub Pages의 index.html을 열고, 페이지 안의 iframe에서 Copilot Studio Web Chat을 불러옵니다. 대화 입력과 AI 응답 처리는 Copilot Studio 측에서 수행합니다.

이 저장소는 정적 웹 화면을 제공합니다. 자체 모델 API 호출, 파일 파싱, 사용자 인증 서버, 대화 저장 기능을 구현하지 않습니다. Copilot Studio 측 데이터 처리·저장 정책은 별도로 확인해야 합니다.

## 재현 및 설정

### 기존 에이전트를 연결하는 방법

1. 본인의 Copilot Studio 환경에서 에이전트 게시 상태와 웹 채널 이용 가능 여부를 확인합니다.
2. 해당 환경에서 제공하는 웹 채팅/임베드 주소를 복사합니다. 관리자 정책과 인증 요구사항을 확인합니다.
3. index.html의 iframe src와 하단 새 창 링크 href를 **같은 주소**로 교체합니다.
4. 이 저장소를 복제한 경우 기존 운영자의 환경 주소를 그대로 사용하지 않습니다.
5. GitHub 저장소의 Settings → Pages에서 배포 방식과 배포 주소를 확인합니다. 메뉴는 권한에 따라 다를 수 있습니다.
6. docs/TESTING.md에 따라 본인의 배포 주소에서 테스트합니다.

브라우저에 전달되는 HTML은 공개됩니다. 비밀번호, API 키, 액세스 토큰, 인증 비밀을 코드에 넣지 않습니다.

### Copilot Studio 내부 구성을 기록할 항목

운영자가 실제 설정을 확인한 뒤 아래 항목을 별도 문서에 기록합니다.

- 에이전트 표시 이름과 게시 버전
- 모델·연결된 하위 에이전트·도구 목록
- 질문 종류별 분배 조건과 실패 시 처리
- 지식 자료의 출처·갱신 날짜
- 웹 검색 및 파일 처리 지원 범위
- 인증 방식과 사용 가능한 사용자 범위
- Power Automate를 연결했다면 흐름 목적과 입력·출력
- 실행 기록에서 확인한 사례와 개인정보를 가린 증빙

내부 구성이 기록되기 전에는 멀티 모델 처리 구조의 완전한 재현이 어렵습니다.

## 테스트 방법과 결과

1. [테스트 절차](docs/TESTING.md)를 읽습니다.
2. [CSV 기록표](tests/test-cases.csv)를 엑셀 등에서 엽니다.
3. 각 질문을 실행하고 실제 답변과 관찰 내용을 기록합니다.
4. 내부 분배 확인이 필요한 항목은 Copilot Studio 실행 기록도 확인합니다.
5. 실패를 수정한 뒤 같은 질문을 다시 실행합니다.

**질문 30개는 설계된 테스트이며 아직 AI에 실행한 결과가 아닙니다.** 실제 답변·성공률·응답 시간은 임의로 작성하지 않습니다. 코드 검사 및 브라우저 확인 결과는 [검증 기록](docs/VERIFICATION.md)에 구분해서 남깁니다.
