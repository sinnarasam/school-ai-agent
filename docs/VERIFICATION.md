# 검증 기록

기록 날짜: 2026-10-26 (한국 시간)

## 검증 범위

- 대상: 저장소의 HTML 및 문서
- AI 내부 설정: 접근·변경하지 않음
- 질문 30개: 테스트 설계 완료, AI 실행 미실시
- 실사용 성공률: 산출하지 않음

## 코드에서 확인한 기존 문제

- 별도 Send 폼은 입력을 비우기만 하고 AI에 전송하지 않았음
- 검색·메뉴 버튼에 동작이 없었음
- 화면 언어와 기본 안내가 영어였음
- 고정 시각과 가상 사용자 말풍선이 표시되었음
- 파일 첨부 URL 옵션이 false였음

## 수정 내용

원래 에이전트 연결 주소를 유지하면서 별도 입력 폼·가상 버튼·고정 상태·가상 사용자 대화를 제거했습니다. 한국어 안내, 개인정보 주의 문구, 새 창 링크를 추가했습니다.

### 브라우저 검사: 환경 제약으로 미실행

Playwright 실행을 시도했으나 Chromium 실행 파일이 설치되어 있지 않아 페이지 렌더링 검사를 진행하지 못했습니다. PC/모바일 화면, iframe 실제 로드, 채팅 전송, 모델 분배, 파일 처리, 웹 검색은 검증되지 않았습니다.

테스트 질문의 실제 답변이나 성공률은 작성하지 않았습니다. 운영 환경에서 docs/TESTING.md를 따라 후속 검증해야 합니다.

### 모델 분배 관찰

- 글쓰기(W01) 답변에는 sonnet5, 계산·수학(S05, C01) 답변에는 gpt56 마커가 붙었습니다. 한계대응(L01, L04)에는 마커가 없어 오케스트레이터가 직접 응답한 것으로 보입니다.
- 이 마커는 채팅 화면에 표시된 값이므로 보조 근거입니다. Copilot Studio 테스트·실행 기록(활동 로그)으로 실제 호출된 모델·도구를 대조하는 작업은 아직 하지 못했습니다.
- 사유: 실행 기록 확인에 쓸 브라우저 세션이 에이전트가 속한 환경(테넌트 Default-b191802e…)이 아닌 다른 테넌트 계정으로 로그인되어 있어 해당 에이전트에 접근할 수 없었습니다. 에이전트 소유 계정으로 로그인한 뒤 확인해야 합니다.

### 수정 대상 (오류 수정 단계)

1. [[SCHOOLAI_MODEL:…]], [[SCHOOLAI_STATUS:…]] 내부 마커가 사용자 화면에 그대로 노출됨. 최종 답변 전송 전 제거하거나 내부 변수로만 유지.
2. STATUS 메시지가 별도 말풍선으로 전송됨(C01). 사용자에게 보내지 않도록 수정.
3. 수식이 $…$ 구분자 그대로 표시됨(C01). 일반 텍스트 출력으로 지시.
4. 파일 업로드 안내와 채널 설정 불일치(L01). 첨부 비활성 채널에서는 텍스트 붙여넣기 안내로 변경하거나 첨부 활성화 여부 결정.
