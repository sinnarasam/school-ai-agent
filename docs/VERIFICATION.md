# 검증 기록

기록 날짜: 2026-10-26 (한국 시간)

## 검증 범위

- 대상: 저장소의 HTML 및 문서
- AI 내부 설정: 접근·변경하지 않음
- 질문 30개: 테스트 설계 완료, AI 실행 미실시
- 실사용 성공률: 산출하지 않음

## 코드에서 확인한 기존 문제

- 별도 Send 폼은 입력을 비우기만 하고 AI에 전송하지 않았음
- 검색·메뉴 버튼에 동작이 없었음
- 화면 언어와 기본 안내가 영어였음
- 고정 시각과 가상 사용자 말풍선이 표시되었음
- 파일 첨부 URL 옵션이 false였음

## 수정 내용

원래 에이전트 연결 주소를 유지하면서 별도 입력 폼·가상 버튼·고정 상태·가상 사용자 대화를 제거했습니다. 한국어 안내, 개인정보 주의 문구, 새 창 링크를 추가했습니다.

## 테스트 결과

검사 실행 후 아래에 코드·브라우저 결과를 기록합니다. iframe 내부 AI 응답, 모델 분배, 도구 사용은 별도 검증 대상입니다.

### 코드 검사: 통과

- HTML 파싱 및 한국어 문서 언어 확인
- iframe 1개 및 새 창 링크 주소 일치 확인
- 별도 form/input/button이 없는지 확인
- 기존 iframe 주소 및 파일 첨부 비활성 옵션 유지 확인
- 개인정보 안내 문구 확인
- README와 문서의 로컬 링크 대상 존재 확인
- CSV 30개 사례의 고유 ID, 열 구조, 미실행 상태 확인

### 브라우저 검사: 환경 제약으로 미실행

Playwright 실행을 시도했으나 Chromium 실행 파일이 설치되어 있지 않아 페이지 렌더링 검사를 진행하지 못했습니다. PC/모바일 화면, iframe 실제 로드, 채팅 전송, 모델 분배, 파일 처리, 웹 검색은 검증되지 않았습니다.

테스트 질문의 실제 답변이나 성공률은 작성하지 않았습니다. 운영 환경에서 docs/TESTING.md를 따라 후속 검증해야 합니다.
